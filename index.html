Rekapitulasi Pendidikan (Per Satker)

ℹ️ Jenjang pendidikan dideteksi otomatis dari gelar pada kolom Nama (mis. S.H., SH, S.Kom, M.H., MH, Dr., dr., A.Md, dsb). Pegawai tanpa gelar akademik dikelompokkan sebagai SLTA.

Rekapitulasi Eselon Kosong (Per Satker)

ℹ️ Menampilkan jumlah jabatan struktural yang terisi dan kosong pada tiap tingkat Eselon (II/III/IV/V), berdasarkan kolom Eselon dan Jabatan pada data pegawai. Pegawai berstatus "Dikaryakan" tidak dihitung.

Rekapitulasi Jabatan Kosong

ℹ️ Daftar jabatan struktural yang wajib ada berdasarkan tipe satuan kerja (Kejaksaan Tinggi / Kejaksaan Negeri Tipe A / Tipe B / Cabang Kejaksaan Negeri) namun belum terisi oleh pegawai manapun.

Rekapitulasi Masa Kerja (Lama Menjabat)

ℹ️ Tampilan sama seperti Rekap Jabatan & Eselon (per Eselon / jabatan, klik untuk membuka daftar nama). Di dalam tiap daftar, pegawai diurutkan dari lama menjabat paling lama (paling atas) berdasarkan kolom "Lama Menjabat (TMT)", lengkap dengan Jabatan dan Gol/Pangkat.

🔗 Sumber Data Otomatis (Google Sheets)

✅ Aplikasi ini sudah terhubung ke Google Sheets data pegawai Kejaksaan Tinggi Aceh secara bawaan. Data otomatis termuat setiap aplikasi dibuka, tanpa perlu setting apapun.

Untuk admin: cara memperbarui data — buka Google Sheets tersebut, lalu File → Import → Replace current sheet dengan file Excel terbaru. Semua orang yang membuka aplikasi ini akan otomatis melihat data terbaru.

Ingin memakai sumber data lain (khusus perangkat ini saja)? Tempel link Google Sheets lain di kolom di bawah (pastikan sudah di-share "Anyone with the link"), lalu klik Simpan & Muat. Klik "Hapus Link" untuk kembali ke sumber data bawaan.
